คู่มือการติดตั้ง Client Server
1
สร้าง Client Server แล้วกด Copy Linux Command หรือ Download
ลิงก์ใช้ได้ครั้งเดียว หมดอายุใน 2 นาที — หมดอายุแล้วกด Regenerate Token
2
โหลดและแตก zip บนเครื่อง Client Server
sudo mkdir -p /opt/securelog-agent wget --no-check-certificate -O agent_package.zip "<ลิงก์ที่ copy มา>" sudo unzip agent_package.zip -d /opt/securelog-agent
3
รัน setup.sh (เป็น root, รันซ้ำได้)
cd /opt/securelog-agent sudo ./setup.sh
4
เช็คผล — ต้อง active ทั้งคู่ และขึ้น Online ใน ~15 วินาที
systemctl status securelog-agent filebeat journalctl -u securelog-agent -f
